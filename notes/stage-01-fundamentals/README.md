## Фундаментальные типы, signed/unsigned, sizeof и auto

- `bool` хранит `true` или `false`; `char` — один элемент символьного типа; `int` и другие целочисленные типы хранят целые числа; `float`, `double` и `long double` хранят приближённые вещественные значения.
- `signed` допускает отрицательные значения, `unsigned` — только неотрицательные. Точные размеры и границы зависят от типа и платформы; используйте `sizeof` и `std::numeric_limits<T>` из `<limits>`.
- Для unsigned арифметика выполняется по модулю 2 в степени числа бит значения: `0u - 1u` даёт максимальное значение типа `unsigned int`. Переполнение знакового целого — неопределённое поведение: полагаться на циклический переход нельзя.
- При сравнении и вычислениях signed с unsigned происходят преобразования типов; например, `-1 < 1u` даёт `false` на типичной платформе, поскольку `-1` преобразуется в большое unsigned-значение. Смешивайте такие типы осторожно.
- `sizeof(T)` возвращает размер в байтах C++; `sizeof(char) == 1`, но число бит в таком байте задаёт `CHAR_BIT` из `<climits>`. Результат и размер типов платформозависимы.
- `auto` выводит тип из инициализатора: `auto x = 10` — `int`, `auto y = 10.0` — `double`, `auto z = 10u` — `unsigned int`. Сам по себе `auto` не означает ссылку и обычно выводит значение-копию.

## const, constexpr, область видимости и время хранения

- `const` запрещает изменение объекта через это имя после инициализации; значение может быть известно только во время выполнения.
- `constexpr` для переменной требует инициализации константным выражением и делает объект неизменяемым. `constexpr`-функция может вычисляться на этапе компиляции при подходящих аргументах и контексте, но может вызываться и во время выполнения.
- Область видимости определяет, где имя доступно в исходном коде; блок `{ ... }` создаёт вложенную область видимости. Сокрытие имени во внутреннем блоке не изменяет внешнюю переменную.
- Время хранения описывает, когда существует объект: автоматическое — до выхода из соответствующего блока; статическое — на протяжении работы программы, в том числе для локальной переменной `static` (она сохраняет значение между вызовами). Само имя локальной `static`-переменной видно только в её блоке.
- Динамически выделенные объекты живут до освобождения, независимо от блока, в котором появилась указательная переменная; управление ресурсами и RAII изучим отдельно.
